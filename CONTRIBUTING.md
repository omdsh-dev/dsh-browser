# Contributing

Thanks for taking the time to contribute.

## Development workflow

1. Fork the repository and create a feature branch.
2. Install the dependencies as described in the README.
3. Make focused changes and add tests where it makes sense.
4. Run the local build and test commands before opening a pull request.
5. Open a pull request that explains the change and the motivation.

## Commit messages

Follow the Conventional Commits specification, for example `feat: add retry logic` or `fix: handle empty input`.

## Reporting issues

Use the issue tracker and include reproduction steps, the expected behavior and the observed behavior.
